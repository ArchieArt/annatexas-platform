Architecture decision established in Phase 1 One data container per metric. All dashboard metrics are served by a single shared endpoint, /api/analytics/containers, which authenticates the caller’s role from the session and returns the same numbers regardless of which dashboard (Admin / Chamber / City) renders them. No dashboard-specific query forks. Phase 1 ships the first two containers — New Users and Business Summary — to prove the pattern; subsequent phases add containers (Revenue, Page Views, Funnel, etc.) to the same endpoint.
